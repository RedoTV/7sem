# Лабораторная №1. Распознавание рукописных цифр на MNIST

## 1. Запуск

Используется **уже существующее uv-окружение `venvs/tensorflow`**, новое не нужно.
Из корня проекта `/home/vadim/7sem/ai`:

```bash
source venvs/tensorflow/bin/activate
cd lab1
python main.py train            # обучение, 5 эпох
python draw.py                  # нарисовать цифру мышью
python main.py predict my5.png  # или распознать свою картинку
```

В окне нарисуй одну крупную цифру с отступами от краёв, нажми «Распознать».
«Очистить» стирает рисунок. Для фотографии: обрежь её до одной цифры,
используй ровный светлый фон и тёмный штрих. Поддерживается и светлая цифра
на чёрном фоне. Несколько цифр сразу программа не разделяет!

Обучать перед каждым распознаванием **не нужно**. Сеть сохраняется рядом
с кодом в `lenet_mnist.keras`. Повторный `train` обучает новую сеть с нуля
и перезаписывает этот файл. Старый `mnist_model.keras` не используется и не изменяется.

Для изменения длительности обучения:

```bash
python main.py train --epochs 10
```

При первом обучении необходим интернет: Keras скачает MNIST в `lab1/.keras/`.
После скачивания датасета обучение и распознавание работают локально.
Окно рисования требует графического рабочего стола и Tkinter; через SSH без
графики используй `predict`. Tkinter — компонент Python, не пакет pip.

В существующее окружение добавлен Pillow (для изображений). Если библиотеки
потребуется установить заново, из корня проекта:

```bash
uv pip install --python venvs/tensorflow/bin/python -r lab1/requirements.txt
```

`requirements.txt` фиксирует версии основных библиотек проверенного окружения.
Команда `source` активирует окружение только в текущем терминале: меняет PATH,
чтобы `python` брался из venv. `uv` управляет окружением и пакетами, а TensorFlow
выполняет вычисления. Для выхода из окружения: `deactivate`.

## 2. Что делает лабораторная

**Задача:** по изображению одной рукописной цифры предсказать класс от 0 до 9.
MNIST содержит 60 000 обучающих и 10 000 тестовых изображений, каждое —
28×28 пикселей в оттенках серого. Метка — правильный ответ, например `7`.

При обучении сеть видит изображение, выдаёт ответ, сравнивает его с меткой
и корректирует веса. При распознавании своего рисунка веса уже не меняются.
Высокая точность на MNIST не гарантирует такую же точность на фотографиях:
почерк, фон и толщина линий могут отличаться от обучающих примеров.

## 3. CNN, LeNet-5 и ReLU простыми словами

**CNN** — свёрточная нейросеть. В отличие от обычной полносвязной сети,
она сначала работает с двумерной картинкой, сохраняя информацию о соседних
пикселях. Маленький обучаемый фильтр перемещается по изображению и ищет
полезные признаки: линии, изгибы и их сочетания. Мы не программируем эти
признаки вручную: значения фильтра подбираются при обучении.

**LeNet-5** — классическая архитектура для распознавания цифр. Здесь её
**упрощённая современная адаптация**, а не точная историческая копия:
вход 28×28 вместо 32×32, первая свёртка с `padding="same"`, активация ReLU,
современный выход softmax и оптимизатор Adam. Сохраняются два свёрточных
блока, average pooling и размеры 6, 16, 120, 84, 10. В оригинале отличались
активации, некоторые соединения, pooling и выходной слой.

**ReLU(x) = max(0, x)**: отрицательные значения заменяет нулём,
положительные оставляет. Например, `[-2, 0, 3] → [0, 0, 3]`.
Она добавляет нелинейность: без нелинейных преобразований цепочка линейных
операций не могла бы моделировать сложные зависимости.

### Архитектура нашей сети

Размеры ниже указаны для одного изображения, без размера пакета:

| Слой | Размер выхода | Смысл |
|---|---|---|
| Input | 28×28×1 | Один канал серого |
| Conv2D, 6 фильтров 5×5, ReLU, same | 28×28×6 | Шесть карт признаков |
| AveragePooling2D, 2×2 | 14×14×6 | Усреднение каждого блока 2×2 |
| Conv2D, 16 фильтров 5×5, ReLU | 10×10×16 | Более сложные признаки |
| AveragePooling2D, 2×2 | 5×5×16 | Уменьшение карт признаков |
| Flatten | 400 | Превращение карт в вектор |
| Dense + ReLU | 120 | Комбинирование признаков |
| Dense + ReLU | 84 | Следующий уровень классификации |
| Dense + softmax | 10 | Оценки для классов 0–9 |

`same` дополняет края нулями и сохраняет размер при шаге 1.
Во второй свёртке действует `valid` по умолчанию: `14 - 5 + 1 = 10`.
Pooling с шагом 2 уменьшает высоту и ширину вдвое, число каналов не меняет.
`Flatten` не обучается: просто переставляет числа в одну последовательность.
Всего в сети **61 706 обучаемых параметров** (весов и смещений).

## 4. Весь main.py по блокам

### Импорты и пути

- `argparse` читает команды `train`, `predict` и их параметры из терминала.
- `os` задаёт настройки TensorFlow через переменные окружения.
- `Path` удобно составляет пути к файлам.
- `numpy` работает с массивами пикселей и выходами сети.
- `tensorflow` предоставляет Keras: слои, обучение, сохранение.
- `Image`, `ImageOps` из Pillow читают и преобразуют картинки.

`CUDA_VISIBLE_DEVICES=-1` отключает GPU: для этой небольшой лабораторной
достаточно CPU, CUDA устанавливать не требуется. `TF_CPP_MIN_LOG_LEVEL`
уменьшает число служебных сообщений (не гарантирует отсутствие всех предупреждений).
Эти настройки идут **до импорта TensorFlow**, иначе он уже мог выбрать устройство.
`KERAS_HOME` задаёт локальную папку кэша, если пользователь не указал свою.
`Path(__file__).parent` означает папку самого скрипта. Поэтому модель сохраняется
в `lab1`, независимо от того, откуда был запущен Python.

### build_model(): создание сети

`Sequential([...])` соединяет слои последовательно: выход одного становится
входом следующего. `Input(shape=(28, 28, 1))` задаёт форму одной картинки.
Первая цифра в `Conv2D(6, (5, 5), ...)` — количество фильтров, `(5, 5)` —
размер каждого фильтра. Остальные слои разобраны в таблице выше.
`return` возвращает созданную, но пока необученную сеть.

### train(epochs): подготовка данных

`set_random_seed(42)` фиксирует генераторы случайных чисел для более
воспроизводимого эксперимента. На разных версиях библиотек и оборудовании
результат всё равно может немного различаться.

`mnist.load_data()` возвращает две пары:

- `x_train` — обучающие картинки; `y_train` — их правильные классы;
- `x_test` — тестовые картинки; `y_test` — их правильные классы.

`astype("float32")` переводит целые яркости в вещественные числа.
Деление на `255.0` нормализует яркость: 0 — чёрный, 1 — белый.
`[..., np.newaxis]` добавляет ось канала: форма `(60000, 28, 28)` становится
`(60000, 28, 28, 1)`. Многоточие означает «оставить прежние измерения».
Тестовые изображения обрабатываются так же. Метки не делятся на 255:
это номера классов, а не яркости.

### compile(): правила обучения

- `optimizer="adam"` — алгоритм обновления весов по градиентам ошибки.
- `loss="sparse_categorical_crossentropy"` — ошибка многоклассовой
  классификации с целочисленными метками. `sparse` означает, что ответ
  хранится числом `7`, а не вектором из десяти элементов.
- `metrics=["accuracy"]` — дополнительно показывать долю правильных ответов.

Loss и accuracy — не одно и то же: loss учитывает оценки классов, а accuracy
только совпадение самого вероятного класса с правильным.
`model.summary()` печатает слои, формы и число параметров.

### fit(): обучение

`epochs=5` — пять проходов по обучающей части данных.
`batch_size=64` — веса обновляются после пакета примерно из 64 картинок,
а не после просмотра всего датасета целиком.
`validation_split=0.1` резервирует 10% исходных обучающих данных:
54 000 картинок используются для обновления весов, 6 000 — для валидации.
Keras отделяет валидационную часть до перемешивания обучающих примеров.
`verbose=2` выводит одну строку итогов каждой эпохи.

Для каждого пакета Keras автоматически выполняет:
1. Прямой проход — вычисляет оценки десяти классов.
2. Вычисление loss по правильным ответам.
3. Обратное распространение — вычисляет градиенты по весам.
4. Adam обновляет веса, стремясь уменьшить loss.

Валидационные данные не обновляют веса. Если тренировочная accuracy растёт,
а валидационная падает, это может быть признаком переобучения.

### evaluate() и save()

`evaluate` проверяет сеть на отдельных 10 000 тестовых примерах,
не использованных для обучения и валидации. `verbose=0` отключает прогресс.
`{accuracy:.2%}` выводит долю как процент с двумя знаками после запятой.
`save` сохраняет архитектуру и веса в файл `.keras`.

### prepare_image(image): своя цифра

Собственный рисунок нужно привести к формату, похожему на MNIST:

1. `convert("RGBA")` добавляет/сохраняет альфа-канал прозрачности.
2. `alpha_composite` накладывает картинку на белый фон: прозрачность PNG
   не превращается случайно в чёрный фон.
3. `convert("L")` переводит картинку в оттенки серого.
4. Из четырёх краёв собирается массив `border`. Если его медианная яркость
   выше 127, фон считается светлым и `invert` меняет чёрное с белым местами.
   Предполагается, что на краях преимущественно фон.
5. `autocontrast` растягивает диапазон яркостей.
6. `point(lambda ...)` строит вспомогательную маску: яркости выше 50 становятся
   белыми, остальные чёрными. `lambda` здесь — короткая функция одного аргумента.
7. `getbbox()` находит прямоугольник вокруг непустых пикселей маски.
   Если их нет, возникает `ValueError` с понятным сообщением.
8. `crop` обрезает лишние поля исходной серой картинки. Маска нужна лишь
   для поиска границ: полутона самого рисунка сохраняются.
9. `thumbnail((20, 20), ...)` вписывает рисунок в квадрат 20×20 с сохранением
   пропорций. Очень маленькие исходники не увеличивает. `LANCZOS` сглаживает
   изменение размера.
10. Создаётся чёрный холст 28×28, цифра вставляется по центру ограничивающей рамки.
11. Нормализация и две новые оси дают `(1, 28, 28, 1)`:
    первый `1` — одна картинка в пакете, последний — один канал.

Это простая подготовка, а не универсальная обработка фотографий. Сложный фон,
тени, цифра у края и несколько символов могут давать неверный результат.
Позиционирование по центру рамки также проще точного центрирования по массе.

### load_model() и predict()

`load_model` проверяет существование файла и загружает обученную CNN.
Если файла нет, сообщает, какой командой обучить сеть.

`model.predict(...)[0]` берёт выход первой (единственной) картинки пакета:
массив из десяти оценок softmax, их сумма примерно равна 1.
`np.argmax` возвращает индекс наибольшей оценки. Индекс и есть цифра:
если максимум у элемента №7, ответ — `7`.
Функция возвращает пару: цифра и её оценка.

**Softmax 99% не означает гарантированные 99% вероятности правильного ответа.**
Сеть может уверенно ошибаться, особенно на рисунках, непохожих на MNIST,
и не умеет надёжно определять «это вообще не цифра».

### main(): управление из терминала

`add_subparsers` создаёт подкоманды. У `train` есть целочисленный параметр
`--epochs` (по умолчанию 5), у `predict` — обязательный путь к изображению.
`parse_args()` разбирает аргументы, а `if` выбирает нужное действие.
Число эпох проверяется на положительность.
`with Image.open(...)` гарантирует закрытие файла после работы.
`try/except` превращает типичные ошибки файла/картинки в короткое сообщение.

`if __name__ == "__main__":` запускает `main()` только при непосредственном
запуске файла. При `from main import ...` из `draw.py` обучение не начинается.

## 5. Весь draw.py по блокам

- `tkinter` создаёт окно, холст, надпись и кнопки. `messagebox` показывает предупреждение.
- `ImageDraw` рисует на PIL-картинке; из `main.py` импортируются общие функции
  загрузки и распознавания, чтобы не дублировать обработку.
- `SIZE=280` — размер холста, `WIDTH=18` — толщина штриха. Перед подачей в CNN
  рисунок всё равно станет 28×28.
- `main()` один раз загружает модель. Если модель отсутствует, печатает подсказку.
- `Tk()` создаёт окно, `title` задаёт заголовок, `Canvas` — белый холст.
  `pack` размещает виджеты, `padx/pady` задают отступы.
- `StringVar` хранит изменяемый текст результата; надпись `Label` связана с ним.
- `image` — копия рисунка в памяти Pillow, `painter` позволяет её изменять.
  Мы рисуем одновременно на видимом Canvas и на `image`: нейросети нужна
  картинка, а не объект интерфейса.
- `previous` хранит предыдущую точку мыши или `None`, если штрих ещё не начат.
- Вложенная функция `paint(event)` получает координаты `event.x`, `event.y`.
  Соединяет предыдущую точку с новой и рисует круг на конце. `*previous`
  распаковывает пару `(x, y)`; `*coords` передаёт координаты отдельными аргументами.
- `nonlocal previous` позволяет менять переменную из окружающей функции
  `main`, а не создавать другую локальную переменную с тем же именем.
- `release` сбрасывает предыдущую точку после отпускания мыши: разные штрихи
  не соединяются случайной линией.
- `clear` удаляет объекты Canvas и закрашивает PIL-картинку белым.
- `recognize` передаёт PIL-картинку общей функции `predict` и обновляет надпись.
  Пустой рисунок вызывает предупреждение вместо падения программы.
- `bind` связывает нажатие, движение с зажатой кнопкой и отпускание с функциями.
- `Button(command=recognize)` передаёт саму функцию, **без скобок**: выполнить
  её нужно позже, при нажатии, а не во время создания кнопки.
- `mainloop()` запускает цикл обработки событий и работает до закрытия окна.

## 6. Результат проверочного запуска

В существующем `venvs/tensorflow` сеть обучена 5 эпох на CPU:

- тестовая accuracy: **98,33%** на 10 000 изображениях;
- тестовый loss: **0,0552**;
- валидационная accuracy последней эпохи: **98,18%**.

Проверены загрузка сохранённой сети, форма и тип входного массива, одинаковая
обработка противоположных цветов фона, отклонение пустой и полностью
прозрачной картинки. Программно нарисованная семёрка распознана как `7`.
Также проверены создание окна Tkinter, события рисования, кнопки
«Распознать» и «Очистить». Это проверка работоспособности, не измерение
точности на реальных рисунках пользователя.
