# Лаб. 2 — Transfer Learning: готовая MobileNetV2 -> дообучение на MNIST

## Запуск

```bash
./venvs/tensorflow/bin/python lab2/mobilenet_transfer.py
```

Первый прогон обучает голову сети (~10–15 мин на CPU) и сохраняет веса в
`lab2/model/mobilenet_mnist_head.weights.h5`. Повторные прогоны подхватывают
готовые веса и работают за ~1 минуту. Графики открываются в интерактивных
окнах matplotlib.

## Идея (связь с лабой 1)

В лабе 1 готовая MobileNetV2 (веса ImageNet) применялась к MNIST «как есть»,
без обучения, — получилось ~13.5%: сеть знает фотки кошек и машин, но никогда
не видела рукописных цифр. В лабе 2 та же сеть **дообучается**: zero-shot
13.5% превращается в ~96–97%.

Что именно делаем с готовой сетью:

1. **Отсекаем голову** — `include_top=False` убирает родной классификатор
   на 1000 классов ImageNet, остаётся «экстрактор признаков» (154 слоя).
2. **Прикручиваем свою голову на 10 выходов** — по числу цифр:
   `GlobalAveragePooling2D -> Dense(128, relu) -> Dropout(0.2) -> Dense(10, softmax)`.
3. **Замораживаем базу** — `base_model.trainable = False`. Обучаются только
   новые ~165 тыс. параметров головы; 2.2 млн готовых весов не трогаем.
4. **ДООБУЧАЕМ** голову на 54 000 картинках MNIST (3 эпохи, Adam).

Это классическая схема transfer learning «feature extraction + новая голова»:
готовая сеть уже умеет выделять универсальные признаки (края, дуги, текстуры) —
мы лишь учим небольшой классификатор переводить их в «цифра 0…9».

## Пайплайн препроцессинга (тот же, что в лабе 1)

```
картинка 28x28, 1 канал (uint8 0..255)
  -> cast float32
  -> tf.repeat x3 канала         (серый -> RGB: сети нужен 3-канальный вход)
  -> tf.image.resize 96x96       (MobileNetV2 ждёт минимум 32x32; 96 — быстро и точно)
  -> preprocess_input            (нормализация MobileNetV2: пиксели [-1, 1])
```

Всё собрано в `tf.data.Dataset` (map/batch/prefetch): картинки не хранятся
в памяти увеличенными, а ресайзятся на лету по батчам.

## Слои и почему такие

| Блок | Что делает | Обучается? |
|---|---|---|
| MobileNetV2 (154 слоя, ImageNet) | превращает картинку в карту признаков 3x3x1280 | нет, заморожена |
| GlobalAveragePooling2D | усредняет карту признаков в вектор 1280 | — |
| Dense(128, relu) | комбинирует признаки ImageNet под задачу цифр | да |
| Dropout(0.2) | при обучении отключает 20% нейронов — защита от переобучения | — |
| Dense(10, softmax) | 10 вероятностей «это цифра 0…9» | да |

Итого: ~2.2M готовых параметров (заморожены) + ~165K обучаемых.

## Нюанс этой сборки Keras (важно!)

В Keras 3.15 (TF 2.21) у `model.compile()` сигнатура:

```python
compile(optimizer, loss, loss_weights, metrics, ...)
```

— `loss_weights` стоит **третьим**, а не `metrics`. Поэтому вызов
`compile('adam', 'sparse_categorical_crossentropy', ['accuracy'])` запишет
строку `'accuracy'` в **веса лосса** и упадёт с загадочной ошибкой
`dtype='string' is not a valid dtype for Keras type promotion`.
В скрипте все аргументы переданы по именам — ошибки нет.
