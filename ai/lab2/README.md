# Лаб. 2 — MNIST через готовую предобученную CNN (TensorFlow/Keras)

## Запуск

```bash
./venvs/tensorflow/bin/python lab2/mnist_pretrained.py
```

Скрипт сам скачает веса (один раз, в `model/`) и откроет 4 интерактивных окна
с графиками (matplotlib). Обучения нет вообще — только загрузка готовых весов
и предсказание. Точность на тесте: **~99%**.

## Что за библиотеки тут задействованы

| Импорт | Что это | Зачем здесь |
|---|---|---|
| `tensorflow as tf` | библиотека глубокого обучения от Google | считает нейросети (тензорные операции), в неё встроен Keras |
| `tf.keras` | «фронтенд»-API поверх TensorFlow | готовые блоки: слои, модели, датасеты. Всё про нейросети берём отсюда |
| `numpy as np` | массивы и математика | accuracy, гистограммы, argmax по вероятностям |
| `matplotlib.pyplot` | построение графиков | 4 окна: примеры, матрица ошибок, уверенность, точность по цифрам |

## Как устроена сеть (Sequential = стек слоёв «сверху вниз»)

```
Вход (28, 28, 1)  — чёрно-белая картинка 28x28
   ↓ Conv2D(32, 3x3, ReLU)   32 фильтра 3x3 скользят по картинке и ищут признаки:
   │                            края, штрихи, углы. Выход: карта 26x26x32
   ↓ MaxPooling2D(2x2)        сжатие вдвое (13x13x32): из каждого квадрата 2x2
   │                            остаётся максимум — грубая форма, меньше расчётов
   ↓ Conv2D(64, 3x3, ReLU)    теперь ищет сложные признаки из простых: петли, крючки.
   │                            Выход: 11x11x64
   ↓ MaxPooling2D(2x2)        сжатие до 5x5x64
   ↓ Flatten                  разворот 5*5*64 = 1600 чисел в один вектор
   ↓ Dropout(0.5)             при обучении случайно выключал 50% нейронов
   │                            (защита от зубрёжки); на предсказании — пустой
   ↓ Dense(10, softmax)       10 выходов = 10 цифр; softmax делит на сумму,
                                чтобы получились вероятности (в сумме дают 1)
```

Всего **34 826 обученных параметров** (весов) — модель весит 455 КБ.

## Пайплайн скрипта по шагам

1. **Скачать веса** `.h5` — файл со всеми 34 826 числами-весами, обученными кем-то до нас.
2. **`keras.models.load_model(..., compile=False)`** — собрать из файла сеть в памяти.
   `compile=False` — не восстанавливать оптимизатор: он нужен только для обучения.
3. **`keras.datasets.mnist.load_data()`** — тестовые 10 000 картинок (встроены в Keras).
4. **Нормализация `x / 255.0`** — сеть обучалась на пикселях 0..1, значит и подавать
   надо 0..1. Это самая частая ошибка: неподготовленный вход ломает предсказания.
5. **`model.predict(x)`** — forward pass каждой картинки через все слои.
   Выход — таблица 10000x10 вероятностей.
6. **`argmax(axis=1)`** — номер класса с максимальной вероятностью = ответ;
   **`max(axis=1)`** — эта вероятность = уверенность.
7. **Метрики**: accuracy (доля верных), точность по каждой цифре отдельно.

## Ключевые понятия, если спросят

- **Слой** — преобразование данных: свёртка ищет признаки, пулинг сжимает,
  Dense — обычный «полносвязный» классификатор.
- **Forward pass / инференс** — один проход данных через сеть без обновления весов.
- **Transfer learning** — переиспользование чужой обученной сети. Здесь веса
  обучены прямо на MNIST, поэтому 99%; в прошлой версии MobileNetV2 (ImageNet)
  без дообучения давала только ~13% — она никогда не видела рукописных цифр.
- **Confusion matrix** — таблица «что на самом деле x что предсказано»;
  чистая диагональ = всё верно, ошибки видны вне диагонали.
- **Уверенность (confidence)** — максимальная вероятность softmax;
  на верных ответах модель уверена почти на 100%, на ошибках заметно ниже.
