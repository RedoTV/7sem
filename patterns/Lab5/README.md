# Lab5. Proxy (структурный)

## Цель
Показать подмену объекта обёрткой с дополнительной логикой.

## Как работает паттерн
Проблема: настоящий сервис дорогой (сетевая задержка, деньги за запросы),
а клиент часто спрашивает одно и то же.

Решение: прокси — класс с тем же интерфейсом, что и сервис. Клиент думает,
что работает с сервисом, а на самом деле — с обёрткой. Прокси выполняет
дополнительную работу до (или вместо) вызова настоящего объекта, а сложные
запросы передаёт ему.

## Как реализовано
| Класс | Роль |
|-------|------|
| `ILlmService` | общий интерфейс прокси и сервиса |
| `RemoteLlmService` | «удалённый» сервис: `Thread.Sleep(1000)` имитирует задержку сети |
| `CachingProxy` | прокси: хранит `Dictionary` с ответами. Есть в кеше — отдаёт сразу, нет — идёт к сервису и сохраняет ответ |
| `Program` (верх) | клиент: не знает, с сервисом или прокси работает |

В демо три вызова: первый медленный (уходили в сеть), второй тот же вопрос —
мгновенный (ответ из кеша), третий новый вопрос — снова сеть.
