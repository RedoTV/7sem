# Лаба 3. Builder (порождающий паттерн)

## Задание
Пошагово собрать сложный объект без «телескопического» конструктора.
Вместо компьютера с CPU/RAM — конфигурация **ИИ-агента**: модель,
системный промпт, temperature, лимит токенов, инструменты, тип памяти,
ретраи, дневной бюджет, стриминг.

## Что показывает паттерн
- один и тот же объект `AiAgent` собирается за разное число шагов;
- fluent-интерфейс: каждый `With*()` возвращает билдер;
- валидация сосредоточена в `Build()` — невалидная конфигурация
  (temperature 4.2, дубли инструментов, отрицательный бюджет) не может
  превратиться в «битый» агент;
- продукт immutable после сборки;
- роль **Director** показана классом `AgentPresets`: заготовки
  `CheapSummarizer()` и `Storyteller()` задают рецепт сборки, не зная
  деталей реализации билдера.

## Запуск
```bash
dotnet run --project Lab3
```

## Структура
- `Agent.cs` — продукт `AiAgent` и вложенный класс `AiAgent.Builder`;
- `Program.cs` — ручная сборка, пресеты-Director, демонстрация валидации.
