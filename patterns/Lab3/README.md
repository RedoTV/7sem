# Lab3. Builder (порождающий)

## Цель
Пошаговое построение сложного объекта без длинного конструктора.

## Как работает паттерн
Проблема: у объекта много настроек (модель, промпт, temperature, лимит токенов...).
Писать конструктор с 5+ параметрами неудобно: легко перепутать порядок аргументов,
а часто нужные значения вообще равны умолчаниям.

Решение: отдельный класс Builder с методом под каждый параметр. Каждый метод
запоминает значение и возвращает сам билдер — поэтому вызовы можно выстраивать
в цепочку. Финальный `Build()` проверяет данные и возвращает готовый объект.
Не вызванный метод = значение по умолчанию.

## Как реализовано
| Класс | Роль |
|-------|------|
| `Agent` | продукт: 5 полей (Model, SystemPrompt, Temperature, MaxTokens, Streaming) |
| `Agent.Builder` | билдер: `SetModel()`, `SetTemperature()`... возвращают `this`; `Build()` собирает объект |
| `Program` (верх) | клиент: собирает два агента разным набором шагов |

В демо видно главное свойство паттерна: первый агент собран со всеми шагами,
второй — только из одного `SetModel()`, остальные поля взяли значения по умолчанию.
В `Build()` одна проверка (`model == null`) — нельзя собрать «пустой» объект.

## Запуск
```bash
dotnet run --project Lab3
```
