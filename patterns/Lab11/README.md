# Лаба 11. Visitor (поведенческий)

## Задание
Иерархия элементов + визиторы, отделяющие алгоритмы от структуры объектов.
Вместо фигур с площадью — **история диалога с ИИ-ассистентом**:
реплика пользователя, ответ модели, вызов инструмента (function calling),
прикреплённое изображение.

## Визиторы
| Визитор                   | Операция                                                     |
|---------------------------|--------------------------------------------------------------|
| `TranscriptRendererVisitor` | читаемая расшифровка диалога                               |
| `TokenCostVisitor`          | подсчёт входных/выходных токенов и стоимости по тарифам   |
| `JsonExportVisitor`         | экспорт в JSON (добавлен без единой правки элементов)     |

## Что показывает паттерн
- двойная диспетчеризация: `element.Accept(visitor)` → `visitor.Visit(concrete)`;
- добавление НОВОЙ операции не требует изменения иерархии элементов
  (JsonExportVisitor), элементы закрыты для изменения;
- тарифы и рендер не смешиваются: каждый визитор отвечает за один алгоритм;
- назван и недостаток: новый ТИП элемента потребовал бы дополнить все визиторы.

## Запуск

```bash
dotnet run --project Lab11
```

## Структура
- `ChatElements.cs` — `IChatElement`, 4 конкретных элемента, `IChatElementVisitor`;
- `Visitors.cs` — визиторы стоимости и расшифровки;
- `Program.cs` — сборка диалога, три операции, JSON-визитор в самом Program.
