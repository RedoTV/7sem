# Лаба 1. Factory (порождающий паттерн)

## Задание
Реализовать фабрику, которая по ключу провайдера создаёт языковую модель,
возвращая общий интерфейс `IChatModel`.

## Тематика
Вместо классических фигур — консольный клиент нейросети. Провайдер выбирается
«конфигурацией», а не правкой кода:

| Ключ     | Продукт           | Особенности                                   |
|----------|-------------------|-----------------------------------------------|
| `cloud`  | `CloudGptModel`   | платная, сетевая задержка, считает стоимость  |
| `local`  | `LocalLlamaModel` | бесплатная, работает на своей GPU             |
| `mock`   | `MockEchoModel`   | мгновенная заглушка для тестов                |

## Что показывает паттерн
- создание объекта отделено от его использования: `ChatSession` не знает
  ни одного конкретного класса модели;
- замена реализации — одна строчка: `ChatModelFactory.Create("local")`;
- фабрика открыта для расширения: `ChatModelFactory.Register("offline", ...)`
  добавляет нового провайдера без изменения кода фабрики (OCP).

## Запуск
```bash
dotnet run --project Lab1            # провайдер по умолчанию: cloud
dotnet run --project Lab1 -- local   # локальная модель
dotnet run --project Lab1 -- mock    # заглушка
```

## Структура
- `ChatModel.cs` — интерфейс «продукта» и три конкретные модели;
- `ChatModelFactory.cs` — фабрика с реестром создателей;
- `Program.cs` — клиент `ChatSession`, работающий только с интерфейсом.
