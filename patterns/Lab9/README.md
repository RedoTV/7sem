# Lab9. Lazy инициализация (порождающий/поведенческий)

## Цель
Оптимизация ресурсоёмких операций: не создавать объект, пока он не понадобился.

## Как работает паттерн
Проблема: объект creation дорого стоит (загрузка весов нейросети — секунды),
но может вообще не понадобиться за время работы программы.

Решение: вместо объекта храним «рецепт» его создания (делегат `Func<T>`)
и флаг «создан ли уже». При первом вызове `Get()` — создаём и запоминаем,
при всех следующих — просто возвращаем сохранённое. Создание откладывается
до последнего момента и выполняется максимум один раз.

## Как реализовано
| Класс | Роль |
|-------|------|
| `MyLazy<T>` | обобщённый ленивый класс: `Func<T> factory`, `bool created`, методы `Get()`, `IsCreated` |
| `NeuralModel` | «дорогой» объект: в конструкторе спит 500 мс — имитация загрузки весов |
| `LazyHolder` | владелец ленивой модели: создаётся мгновенно, потому что хранит не модель, а `MyLazy` |
| `Program` (верх) | клиент |

В демо: `IsCreated == false` сразу после создания холдера; первый `Get()` —
весовой загрузке и «(первый вызов — создаём объект)» в консоли; второй `Get()` —
тот же объект без загрузки.
