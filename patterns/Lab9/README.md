# Лаба 9. Lazy-инициализация (порождающий / поведенческий)

## Задание
Класс `Lazy<T>`, который создаёт объект только при первом вызове `Get()`.

## Тематика
Вместо абстрактного «дорогого объекта» — **загрузка весов нейросети** и
**построение индекса эмбеддингов**: операции по секунды, которые невыгодно
выполнять «на всякий случай».

## Что показывает паттерн
- `MyLazy<T>`: объект не создаётся до первого `Get()`;
  создание хаба моделей — мгновенное;
- ленивое создание выполняется **ровно один раз**, даже если 8 потоков
  одновременно вызывают `Get()` (double-checked locking, барьерная гонка
  в демо №4);
- `IsCreated` позволяет узнать факт инициализации, не запуская её;
- исключение в фабрике не кешируется — объект остаётся несозданным.

## Запуск
```bash
dotnet run --project Lab9
```

## Структура
- `MyLazy.cs` — обобщённый потокобезопасный `MyLazy<T>` (двойная проверка + lock);
- `Program.cs` — 4 демо: создание без загрузки, первый `Get()`, повторные
  `Get()`, одновременный `Get()` из 8 потоков со счётчиками загрузок.
