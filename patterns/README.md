# Лабораторные работы по паттернам проектирования

Тематика всех примеров — вокруг нейросетей и LLM-сервисов: модели, агенты,
диалоги, токены и деньги за них. Нечётные лабы: 1, 3, 5, 9, 11 — на C#,
лаба 7 — на C++ (как указано в задании).

| Лаба | Паттерн | Пример | Язык |
|------|---------|--------|------|
| Lab1  | Factory    | фабрика LLM-провайдеров (облако / локальная / mock) | C# |
| Lab3  | Builder    | пошаговая сборка конфигурации ИИ-агента (+ Director-пресеты) | C# |
| Lab5  | Proxy      | кеширующий прокси к «удалённому» LLM с TTL и статистикой | C# |
| Lab7  | Observer   | подписчики на метрики обучения нейросети (early stopping, чекпойнты, деньги за GPU) | C++ |
| Lab9  | Lazy       | свой потокобезопасный `MyLazy<T>`: ленивая загрузка весов модели | C# |
| Lab11 | Visitor    | операции над историей диалога с ИИ: расшифровка, стоимость токенов, JSON | C# |

## Запуск

C# (нужен .NET SDK 10):
```bash
dotnet run --project Lab1
dotnet run --project Lab3
dotnet run --project Lab5
dotnet run --project Lab9
dotnet run --project Lab11
```

C++ (нужен g++):
```bash
cd Lab7 && make run
```

Подробности по каждой лабе — в её `README.md`.
