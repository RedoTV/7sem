# Лаба 7. Observer (поведенческий) — C++

## Задание
Модель «издатель/подписчик»: наблюдатели оповещаются об изменении состояния
объекта. Вместо классической «температуры» — **обучение нейросети**:
издатель `TrainingRun` на каждой эпохе рассылает метрики (loss, val_accuracy,
learning rate) подписчикам.

## Наблюдатели
| Наблюдатель               | Что делает                                                        |
|---------------------------|-------------------------------------------------------------------|
| `ConsoleLoggerObserver`   | печатает строку метрик эпохи                                       |
| `EarlyStoppingObserver`   | при плато качества N эпох подряд вызывает `run.Stop()` (обратное влияние на издателя) |
| `CheckpointSaverObserver` | при улучшении качества пишет `best_checkpoint.json`               |
| `GpuCostObserver`         | считает GPU-минуты и деньги, отчитывается в конце                 |
| `GradientDebugObserver`   | шумный отладчик — демонстрирует `Detach` на живом издателе        |

## Что показывает паттерн
- слабая связанность: издатель знает только абстрактный `TrainingObserver`;
- подписка/отписка в любой момент (фаза 1 → отписали DEBUG → фаза 2);
- один наблюдатель может влиять на издателя (early stopping);
- защищённый список подписчиков (мьютекс + копия перед оповещением).

## Сборка и запуск
```bash
cd Lab7
make run          # или: g++ -std=c++17 -Wall -Wextra -o lab7_observer main.cpp && ./lab7_observer
```

Побочный артефакт запуска — файл `best_checkpoint.json` с лучшей эпохой.

## Структура
- `main.cpp` — вся реализация: `EpochMetrics`, `TrainingObserver`,
  `TrainingRun` (Subject), пять наблюдателей, `main()` с двумя фазами;
- `Makefile` — сборка.
